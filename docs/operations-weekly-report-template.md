## How to Generate This Report

1. Open `/app/admin/operations` — copy health data
2. Open `/app/admin/incidents` — list opened/resolved incidents
3. Open `/app/admin/support` — count cases by category
4. Open `/app/admin/releases` — list releases this week
5. Check Supabase Dashboard for any additional metrics
6. Fill in this template
7. Review with team
8. Archive the completed report
